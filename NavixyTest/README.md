# NavixyTest

Небольшое iOS-приложение для тестового задания Navixy: список GPS-трекеров, экран одного трекера и карта.

## Что есть в приложении

- сеть на `URLSession`
- локальное хранение на `Core Data`
- offline-first список трекеров
- `pull-to-refresh`
- логирование HTTP-ответов в консоль
- polling координат через `tracker/get_states`
- карта на `MapKit`

## Запуск и использование

1. Запустить проект в Xcode.
2. На первой странице карта со списком трекеров.
3. При нажатии на трекер, переходит к конкретному месту на карте трекера и отрывается поп-ап с информацией по трекеру.
4. На карте есть кнопки приближения/удаления и возвращение к общему виду карты.
5. По переходу на кнопку "Trackers" переходит на список доступных трекеров.
6. При нажатии на элемент из списка переходит на страницу с информацией по выбранному трекеру.
7. Обновление данных при `pull-to-refresh`.
